MIJANUR RECHARGE — Admin Panel (Netlify ZIP)

UPLOAD:
1. Open https://app.netlify.com/drop on your phone/browser.
2. Upload this ZIP file directly, or extract it and upload the folder containing index.html and config.js.
3. Open the new Netlify URL and sign in with your existing Supabase Auth email/password.

INCLUDED:
Mobile Prepaid, Mobile Postpaid, DTH, Data Card, Electricity, Gas, Water, Landline, Broadband, Insurance, FASTag and Loan EMI dashboard tiles; wallet/account management placeholders; transaction area.

IMPORTANT:
This is the dashboard/frontend. It does NOT perform real recharge or deduct wallet money. Live transactions require an approved recharge API/Bharat Connect provider, operator/biller configuration, secure server-side functions, database tables, wallet ledger and role-based access policies. Do not add secret/service_role keys to browser files.

Supabase Project URL and Publishable key are set in config.js. If your project/key has changed, update them before uploading.
